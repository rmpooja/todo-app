# To-Do Web Application

A simple To-Do web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Save tasks using browser localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage
